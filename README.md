# Iscah Tuzo – Luxury Fashion Website

## Overview

Iscah Tuzo is a modern luxury fashion website designed to showcase premium men's and women's clothing collections through an elegant and responsive user interface. The project demonstrates modern front-end web development techniques by combining beautiful layouts, dynamic content, and intuitive navigation to create an engaging browsing experience.

The website emphasizes simplicity, sophistication, and accessibility while providing visitors with an easy way to explore luxury fashion collections. It is designed to be fully responsive, ensuring a seamless experience across desktops, tablets, and mobile devices.

---

## Project Objectives

The primary objective of this project is to create a visually appealing fashion website that reflects a luxury brand identity while demonstrating practical front-end development skills. The website aims to provide users with a smooth browsing experience, attractive product presentation, and responsive navigation using modern web technologies.

---

## Features

* Elegant and responsive homepage
* Dedicated Men's Collection page
* Dedicated Women's Collection page
* Luxury-inspired white and gold user interface
* Responsive design for multiple screen sizes

## How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Start a local development server (such as Live Server).
4. Open **index.html** in your browser.
5. Explore the homepage, men's collection, women's collection, and login page.

## Challenges Encountered

During development, several challenges were encountered, including dynamically displaying images from JSON files, creating a fully responsive layout, and maintaining a consistent luxury design across all pages. These challenges were addressed using JavaScript's Fetch API, Tailwind CSS utilities, and a modular page structure.
